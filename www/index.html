      Mode d'emploi

      1. Créez un livre puis ajoutez une page par illustration à faire réagir.
      2. Photographiez l'illustration bien à plat, cadrée de près, sans reflet, puis recadrez sur l'image seule (sans le texte ni la table).
      3. Choisissez ce qui se déclenche : une vidéo qui vient se poser sur l'illustration (idéale avec un fond vert rendu transparent), ou un son de la sonothèque.
      4. Lancez la lecture : la première fois, l'appli analyse les illustrations (quelques secondes par page), puis il suffit de montrer le livre à la caméra.
      5. Partagez : exportez le livre en .zip pour l'ouvrir sur une tablette ou un autre poste, ou publiez le .zip en ligne et imprimez le QR code à coller dans le livre.

      Bien choisir les illustrations

      • Les images riches en détails et contrastées sont les mieux reconnues. Les aplats de couleur, les ciels unis, les dessins très simples le sont mal.
      • Deux illustrations trop semblables (même décor) peuvent être confondues : préférez des doubles pages bien différentes.
      • Éclairage homogène, pas de lampe qui se reflète sur un papier glacé.

      Vidéos

      • Formats conseillés : MP4 (H.264) ou WebM, 720p suffit, quelques dizaines de secondes.
      • Une vidéo tournée sur fond vert (avec le Kit Effets Spéciaux par exemple) peut être rendue transparente : le personnage semble sortir du livre.

      Sur tablette et téléphone

      L'appli fonctionne dans le navigateur (Chrome, Safari, Firefox) à l'adresse publiée sur GitHub Pages. Les livres restent enregistrés dans l'appareil. Rien n'est envoyé sur Internet.

      Reconnaissance d'images : MindAR (MIT) · Rendu 3D : three.js (MIT) · Archive : JSZip · QR code : qrcode-generator. Kit réalisé pour le réseau biblio.gironde.
