# Livres publiés

Déposez ici les fichiers .zip exportés depuis l’appli. Une fois le dépôt publié sur GitHub Pages, chaque livre est accessible à l’adresse
https://bibliogironde.github.io/Kit-AR-Livre-Augmente/livres/<nom>.zip — c’est cette adresse à coller dans « Exporter / partager » pour générer le QR code.
